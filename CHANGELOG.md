# Changelog

## [3.2.0] - 2026-08-08

### Changed
- Демо-кнопки ролей убраны с экрана авторизации
- TechSpec страница полностью переработана
- Роутер исправлен: SUPER_ADMIN имеет доступ ко всем страницам
- Все v-show заменены на v-if (21 страница)
- ErrorState локализован (i18n RU/UZ)
- Бандл оптимизирован: ProtocolCreatePage сокращён с 611KB до 19KB

### Fixed
- Пустой экран после авторизации (v-show + transition конфликт)
- Доступ SUPER_ADMIN к /hr и /help маршрутам
- Парсинг узбекских апострофов (U+02BB)

## [3.1.0] - 2026-08-07

### Added
- Командный центр с трёхуровневым drill-down (Республика, Регион, Район)
- KPI-индикация по принципу светофора
- Бифуркационная система скоринга (баллы vs Hit/Miss)

### Changed
- Оптимизация бандла: ленивая загрузка jspdf и html2canvas
- Глобальное обновление CSS и дизайн-системы

## [3.0.0] - 2026-08-06

### Added
- 72 страницы с полным покрытием бизнес-процессов
- 5 ролей: MANAGER, INSTRUCTOR, EMPLOYEE, TECHSPEC, SUPER_ADMIN
- Двуязычная поддержка (русский / узбекский)
- Интеграция с IP-камерами (статические IP 88.x.x.x)
- Генерация протоколов с QR-кодом
- Audit journal для отслеживания действий

### Security
- JWT-аутентификация
- Row-Level Security
- Zero-edit policy для исторических результатов
- Изоляция TechSpec от результатов стрельб
- Обязательная проверка ТБ для допуска на полигон

## [2.0.0] - 2026-07-28

### Added
- Django REST Framework backend
- FastAPI scoring service
- PostgreSQL support
- Docker Compose оркестрация

## [1.0.0] - 2026-07-24

### Added
- Базовый Vue 3 SPA
- Pinia stores
- Tailwind CSS дизайн-система
- Базовая авторизация
